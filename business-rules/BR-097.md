# BR-097 · A provider's endpoints are fixed when the service is declared

## Rule

Code exchange, account reading, renewal, revocation and registration use only the endpoints discovered at `service declare` and kept in the service record; a kept value changes only through `service rediscover`, never in the course of a call.

## Clarifications

- Otherwise a modified metadata document (compromised provider, configuration error, intermediate cache) would silently send the renewal tokens and the application secrets to another host, at every renewal.
- Discovery per the model (§3.1), bounded by BR-084; a non-https endpoint is refused at declaration (code 2). The values are displayed by `service list` and audited at declaration; `service rediscover <id> --confirm <id>` audits the values before and after and does not touch the connections.
