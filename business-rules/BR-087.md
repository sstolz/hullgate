# BR-087 · Upstream secrets are encrypted at rest by the organisation's key

## Rule

Upstream tokens, application secrets and registration secrets are written encrypted (AES-256-GCM, unique nonce, versioned envelope) with a key kept outside the database; a value found in clear in a table, the backup or the `-wal` file fails the test.

## Clarifications

- Source: spec l. 629, 670-671, 760. Envelope ready for a future rotation (C1 a), which is not delivered.
- Each ciphertext is bound to its place: associated data (AAD) = envelope version ‖ table ‖ row id ‖ field name. A ciphertext moved to another row or another field does not decrypt (`access_integrity_error`, BR-088).
- Population (`executable-guards.md` §The population): the sweep covers all the tables and the files of the database after a complete run (authorization, renewal, dynamic registration, provided token); dated finding, commit, instrument to record at delivery.
