# BR-160 · The organisation has one permanent, random public identifier

## Rule

The organisation has exactly one public identifier of 12 characters matching `^[a-z2-7]{12}$`, drawn at random once and derived from nothing; the store refuses any update of a value once set, except the adoption of an imported document's identifier on an instance whose tree is empty (BR-225).

## Clarifications

- Never changed afterwards: no command, setting or later migration touches it, but the import of BR-225 on an empty tree, which adopts the document's identifier so a restored tree keeps its URLs; on a populated tree a foreign identifier is refused.
- It is public: no secret handling, no constant-time comparison, free to appear in logs and audit rows.
- A backup carries it; a restored backup of the same schema keeps it.
- In v1 the instance has one; uniqueness among several is HULL-67's, and the stored form allows it.
