# BR-077 · A placement puts a connection on a role, once

## Rule

A connection is placed on a role, never on another level, only once per (connection, role) pair; a placement on another level, a duplicate or a nonexistent connection is refused. A role accepts several connections with distinct prefixes.

## Clarifications

- The token set stays single whatever the number of placements (BR-089).
- Placing or removing a placement is an audit event (BR-066 v2); nothing changes account silently (spec lines 1127-1128).
