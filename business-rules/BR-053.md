# BR-053 · Operator token: value shown once, only the fingerprint is kept

## Rule

`hullgate token create` prints the token value once on standard output, and the API's issue response returns it once; no later command, response, output or log shows it again.

## Clarifications

- What the database keeps of the token (fingerprint only): BR-072.
- Value: prefix `hg_` followed by 256 random bits encoded in base64url (H7); the prefix lets the secrets guard (BR-003) recognize it. A token presented under another prefix is refused as unknown.
- `token list` displays identifier, label, node path (or `(deleted)`), issuance, expiry, state; never the value nor the full fingerprint.
- Usage: `Authorization: Bearer <valeur>` header (Claude Code, clients without OAuth).
