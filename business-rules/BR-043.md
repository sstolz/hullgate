# BR-043 · The session acts toward prod-gateway only on the operator's explicit go

## Rule

A session act (implementation, review, applying findings, acceptance) performs an action toward the `prod-gateway` server (deployment, verification, reading) only on an explicit go from the operator, given per action or per sequence of actions announced by the session before its execution. An action toward `prod-gateway` without this go is a blocking review finding.

## Clarifications

- The go is the operator's own, given in session; it is recorded in the report of the act or the ticket comment that accounts for the action. A sequence's go covers only the announced actions.
- Creating, displaying, copying or transmitting a secret (key, token, password) remain operator gestures, or go through the operator's go for each act (`behavioural-guardrails.md` §2, point 6); a sequence go does not cover them.
- The evidence for an AC-OP criterion (operations readings on `prod-gateway`) is produced by the operator, who replays the checks themselves; the session records it, it does not produce it to stand in for it.
- Reason: first deployment of an empty database, Traefik and DNS values specific to the operator, deploy key created on the production server; operator preference for copy-paste runbooks.
