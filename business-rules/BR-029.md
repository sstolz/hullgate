# BR-029 · Reproducible image: pinned base, dependencies from the lock only

## Rule

The image is built from base images pinned by multi-architecture index digest and installs only the dependencies frozen by `uv.lock` (`uv sync --locked`); the build tool `uv` does not remain in the runtime image. A `FROM` without a digest or an out-of-sync lock makes the build or the test fail.
