# BR-099 · A tool's role is declared in one place; only a blocking tool makes `make qa` fail

## Rule

Each tool's role is declared only in `QA_TOOLS`; `make qa` ends with `QA: KO <noms>` and a nonzero code if, and only if, a tool with role `blocking` returned `FINDINGS` or `ERROR`; otherwise it ends with `QA: OK` and code 0, whatever the verdicts of the `info` tools. A `blocking` tool does not return `SKIP`: a check it cannot perform is an `ERROR`.

## Clarifications

- An `info` tool returns `ERROR` or `SKIP` without making the aggregator fail; the line remains visible.
- No other file (documentation, skill, project-context) copies the role: they refer to `QA_TOOLS`.
