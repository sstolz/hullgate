# BR-011 · Acceptance run policies fixed before it

## Rule

Before the first test, the bench fixes and commits: refusal of ambiguous requests (T04), default refusal of protected operations when the vault or the revocation check is unavailable (T13), cut delay (T12) strictly shorter than the configured access token lifetime, and a single ContextForge configuration for the 16 tests; a change during the acceptance run invalidates the acceptance run.

## Clarifications

- These policies are those of the gateway specification; a ContextForge that "fails open" (§9) fails T13, it does not change the policy.
