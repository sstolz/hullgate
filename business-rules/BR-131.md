# BR-131 · The gateway's closed vocabularies and its product name are English

## Rule

Every closed vocabulary that a client, a script, an operator's runbook or an audit reader depends on by its exact spelling is English: the CLI groups, verbs, options and accepted values with the keys and values of their JSON and YAML outputs; the error codes and the fixed texts the gateway returns to MCP clients; the issue, outcome, omission and reason values written to the audit or stored in the database; the `make` targets, their variables and verdict lines; the names of compose projects, networks, volumes, files and environment keys; and the product's own name, `hullgate`, in its package, binary, images, containers and every name it presents to a client, an upstream or an authenticator. The identifiers of data at rest are English: the key-check label `hullgate/connections/key-check/v1` and the operator-token prefix `hg_`. A CLI invocation that uses a retired French spelling is refused with the usage error (exit code 2) and changes nothing. Excepted, and only this: the isolation bench's verdict vocabulary (BR-037, BR-071), until the ticket that migrates it.

## Clarifications

- A *closed vocabulary* is a name or value that code compares by equality or that a document quotes as something to type or to expect. Free text — messages, `Refused` bodies, `error_description`, docstrings, comments, the consent page, documents — is not one and follows the project's `language` in its own lot.
- Permanent keeps (not exceptions): the English words `client`, `service`, `application`, `organisation`, `segment`, `format`, `roles`, `principal`; the verdict tokens `GATE:`, `QA`, `DEPLOY:`, `BACKUP:`, `OPS:`; audit action names; OAuth and HTTP `error` codes.
- Historical data keeps its spelling: audit rows written before HULL-57's values were deployed (BR-066 v4) and the bench's `evidence/*.json`.
- The pinned tables are those of F-010 §3.2, plus the data volume default of F-011 §3.1; a new name enters the snapshot only by editing the pinned table in the same change, which is where a reviewer reads its spelling.
- The former product name is not swept by this rule: the former-name guard (`tests/unit/test_former_names.py`, HULL-58) refuses it in every tracked path and file, so sweep G and its kept tokens are gone.

- the keys and refusal codes of the admin API, its cookie and header names (`hullgate_admin`, `X-CSRF-Token`, `X-Hullgate-Activity`) are closed vocabularies under this rule; they are not pinned by the surface snapshot until the API is, which lot A adds.
