# BR-212 · The console is a self-contained bundle; the image holds no Node

## Rule

The console is a static bundle built at image build time and served by the admin listener, with no external origin at runtime, under `Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; connect-src 'self'; font-src 'self'; base-uri 'none'; form-action 'self'; frame-ancestors 'none'`; the runtime image contains no Node, and a Node binary in it or an external request fails the test.

## Clarifications

- Every response of `/admin` also carries `X-Content-Type-Options: nosniff` and `Referrer-Policy: no-referrer`.
- The HTML shell holds no data, needs no session, and is the same for everyone; data needs the API.
- Without a built bundle (unit and integration tests) `/admin` is 404 and the API works.
- Fonts are self-hosted, under an open licence recorded beside them (§8).
