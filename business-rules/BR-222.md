# BR-222 · An import is previewed, and the preview writes nothing

## Rule

Importing a YAML document first returns the list of creations, changes and deletions with the impact of each and a digest of document and state, writing nothing; applying requires that digest, and a state or document that differs gets 409 `import_stale`.

## Clarifications

- An export of the current state previews as empty, byte for byte the BR-070 document: it is the round-trip test.
- `hullgate import --preview <file>` and `--apply <digest> <file>` give the same on the CLI.
