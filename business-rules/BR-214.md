# BR-214 · An irreversible write quotes the impact it was shown

## Rule

An API write that deletes, revokes or changes a path or a sensitivity is refused with 409 `impact_changed` unless it carries the digest of the impact the server computes at that moment, obtained from the matching read.

## Clarifications

- Population at `6f32739`: `tree.delete`, `tree.rename`, `tree.move`, `tree.sensitive` (`delete_impact`, `move_impact`, `sensitive_impact` in `src/hullgate/tree.py`; rename uses the move plan), and, with impacts written by this feature, `connection revoke`, `connection remove`, `client remove`, `application remove`, `service remove`, `application reregister`. Prescribed sweep: every API write whose operation revokes or deletes is in the test's table.
- The dialog shows the numbers: tokens revoked, lineages cut, placements removed, URLs that stop, shares created (BR-079).
- Two tabs editing the same setting: last write wins, both audited; §9.
