# BR-332 · Ticket identifiers are historical references, explained once

## Rule

`HULL-NN` identifiers are historical references to the private tracker before publication: they stay as written, the README's one note explains them, and none is rewritten or turned into a link to a public issue number; a rewritten identifier or such a link is a review finding.

## Clarifications
- The note also says that `#N` names a GitHub issue or pull request of the public repository, except in the tree of tag `v1.0.0`, which still writes private ones that way; that `GH-N`, in a branch name or a cairn-composed field (F-025 §3.6 step 7), names GitHub issue #N; and that review identifiers and workshop report citations are historical (F-025 §3.8 step 6).
- The one-off pass of BR-350, `#N` → `HULL-N`, is not a rewrite under this rule: it spells the prefix of an identifier and renames none.
