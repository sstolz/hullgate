# BR-218 · The audit screen reads and exports; it writes nothing

## Rule

The API offers filtered, paged reading and a JSON Lines export (at most 100 000 entries per export) of the audit, and no route writes to it other than as a trace of an act; each export is itself audited with its filter.

## Clarifications

- Filter on time, actor, path prefix, action, result. Paging by `seq`.
- The entries carry no secret (BR-066), so the export needs no further redaction.
