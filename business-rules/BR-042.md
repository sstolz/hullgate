# BR-042 · Every deployment action is a copy-paste guide

## Rule

Every action on the server that F-004 assumes (reading the Traefik configuration, DNS, clone, `.env`, deployment, verification, backup, scheduling, update, restore) is delivered in a generic guide where each step is a block to paste, its expected result and what to do if it differs; an incomplete step fails the test.

## Clarifications

- Actions are delivered in `docs/guides/`; a step's outcome is its expected result, with no ticket-reporting instruction.
