# BR-232 · The console's main flows work from the keyboard

## Rule

The sign-in, place a connection, issue a token and delete a node flows complete by keyboard alone, with visible focus; a flow that cannot fails the test. Every other act available by pointer is expected to do the same, and an axe audit run in `tests/browser` reports what it finds, as a warning.

## Clarifications

- Inherits the keyboard paths of HULL-18 ("Place in…", F2, Delete, `[`, `]`).
